# Contributing

Thanks for helping.

1. Read [AGENTS.md](AGENTS.md) for the commands and rules.
2. Pick a task from [ROADMAP.md](ROADMAP.md), or open an issue first for a new idea.
3. Branch from `dev`, write a failing test, make it pass. `main` changes only at a release.
4. Run the checks in the Commands section of [AGENTS.md](AGENTS.md); CI runs them on every pull request. Then open a pull request into `dev`, titled with the task ID, for example `M0.6: minimal rule gate`.

Security problems: do not open an issue; see [SECURITY.md](SECURITY.md).

By taking part you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
